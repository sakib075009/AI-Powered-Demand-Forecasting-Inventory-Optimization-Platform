# AI Demand Forecasting and Inventory Optimization

## Project Overview

An end-to-end analytics project combining demand forecasting, inventory planning, replenishment recommendations, and optimization. The project is designed to demonstrate practical applications of Industrial and Production Engineering, Data Science, and Business Analytics.

## Business Objectives

- Analyze historical demand patterns and variability.
- Develop and compare demand forecasting models.
- Evaluate forecasts using MAE, RMSE, WAPE, and forecast bias.
- Calculate safety stock and reorder points.
- Recommend replenishment quantities using inventory position.
- Analyze inventory costs, stockout risk, and service levels.
- Explore inventory optimization and business scenarios.
- Build interactive Power BI dashboards for decision support.
- Implement reproducible data pipelines, automated tests, and safe workflows.

## Technology Stack

- **Programming:** Python
- **Data processing:** pandas, NumPy
- **Forecasting:** statsmodels, scikit-learn
- **Scientific computing:** SciPy
- **Optimization:** PuLP
- **Storage:** CSV and SQLite
- **Visualization:** Matplotlib and Power BI
- **Testing:** pytest
- **Development and version control:** VS Code, Jupyter, Git, GitHub
- **Automation:** GitHub Actions

## Data Strategy

The project will begin with reproducible synthetic demand and inventory data. A suitable public dataset may be added for further validation. Synthetic results will be clearly distinguished from real-world evidence.

## Quality Assurance

The project will use modular Python code, data validation, automated tests, version control, and documented assumptions. Automated workflows that modify tracked data will require integrity checks, validation, and a recovery strategy before changes are applied.

## Project Status

**Current phase:** Repository setup and environment preparation.

Forecasting models, inventory policies, optimization routines, dashboard pages, and performance results will be documented as they are implemented and tested.

## Limitations

Forecasting and inventory recommendations depend on data quality, demand patterns, lead times, cost assumptions, and business constraints. Synthetic-data results alone do not demonstrate real-world business performance.
